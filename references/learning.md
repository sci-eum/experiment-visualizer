# 학생이 실험 과정을 이해할 수 있는지 점검하기

이 자료의 목적은 학생이 실험 전에 전체 흐름을 파악하고, 단계마다 무엇을 어디에 얼마나 어떻게 하는지 이해하도록 돕는 것이다. 자동 검사 통과는 파일·수치·그림의 기술적 확인이며, 학습 효과의 증거는 아니다.

## 제작자가 전달 전에 확인할 것

| 확인할 것 | 확인 방법 | 보완 방법 |
|---|---|---|
| 전체 순서 | 준비물을 읽기 전에 전체 과정의 동작 순서를 볼 수 있는가? | 한눈에 보기의 제목을 짧은 동작 이름으로 쓴다. 관찰 결과를 제목에 쓰지 않는다. |
| 대상과 양 | 긴 설명문을 가리고도 무엇을 어느 기구에 얼마나 넣는지 알 수 있는가? | 기구 이름표·화살표와 `mapping` 대응표를 쓴다. 이름표는 장면 가까이에 둔다. |
| 반복 범위 | 대표 시험관 하나를 그렸을 때 다른 시험관에도 해야 한다는 것이 분명한가? | `repeat`에 대표 그림의 대상과 전체 반복 범위를 함께 적는다. 원문의 '각각'·'모두'를 보존한다. |
| 단계 연결 | 확대되거나 기구가 옮겨져도 앞 단계의 어떤 대상인지 알 수 있는가? | 같은 `id`·이름표·배치를 유지하고 확대 대상 이름을 붙인다. 생략한 반복을 다음 단계의 갑작스러운 변화로 대신하지 않는다. |
| 다음으로 넘어갈 때 | 무엇을 마쳤을 때 다음 동작을 하는지 알 수 있는가? | `checkpoint`로 원문 동작의 완료·시간·관찰 조건을 정리한다. 원문에 없는 수치·성공 기준은 추가하지 않는다. |
| 과학적 표현 | 숨겨 둔 결과가 다른 색·층·상태처럼 보이지 않는가? | 액체 결과 색은 `hideColor:true`로 가리고 빗금·?의 의미를 알린다. 가짜 층으로 나누지 않는다. |
| 읽는 부담 | 해당 학년이 이름표·핵심 안내를 먼저 읽을 수 있는가? | 한 문장에 동작 하나, 짧은 제목을 쓴다. 물질의 정확한 이름과 수치는 유지한다. |
| 화면 크기 | PC·휴대폰에서 대응표와 이름표가 읽히며 3D·시연 단추가 가리지 않는가? | 실제 화면에서 확인한다. 작은 그림 안에 글을 몰아넣지 말고 대응표·반복 안내로 나눈다. |

원문에서 근거를 찾을 수 없는 대상·조건이 있으면 추측해서 채우지 않는다. 원문을 확인하거나 스킬의 멈춤 조건에 따른다. 원문 재구성은 새로운 팁을 지어내는 것과 구별한다.

## 수업에서 간단히 비교하기 (선택)

학생 검토를 하지 않았다는 이유로 자료 제작을 중단하지 않는다. 다음 양식은 교사가 수업 후 실제 효과를 확인할 때 사용한다. 학생의 이름·번호는 기록하지 않고, 자료에는 익명 집계와 오해한 지점만 남긴다.

1. **비교 자료를 맞춘다.** 같은 실험과 같은 수치·순서·결과 공개 범위를 사용한다. 한 자료는 원문 글 안내, 다른 자료는 도식 안내로 준비한다. 두 자료의 설명 내용이 달라서 생긴 차이를 도식 효과로 해석하지 않는다.
2. **조건을 맞춘다.** 비슷한 사전 지식의 학생들을 가능하면 임의로 두 모둠에 나눈다. 같은 시간과 질문, 기기 크기, 교사의 도움 기준을 적용한다. 같은 학생에게 같은 실험 자료를 연달아 보여 주면 두 번째의 연습 효과가 섞이므로 두 모둠 비교를 우선한다.
3. **과정을 설명하게 한다.** 실험을 시작하기 전에 단계 카드를 순서대로 놓기, 물질과 기구·넣을 대상을 연결하기, 반복할 대상과 다음 단계 조건 설명하기를 실시한다. 관찰 결과를 맞혔는지는 절차 이해 점수에 섞지 않는다.
4. **오해와 도움을 기록한다.** 자료를 보고 준비하거나 교사에게 절차를 설명하는 동안 어떤 이름표·화살표·표현에서 멈추는지 기록한다. 교사가 알려 준 뒤 맞힌 답은 독립적으로 이해한 답과 구별한다.
5. **같은 기준으로 비교한다.** 아래 집계에서 정확도, 교사 도움 횟수, 소요 시간, 오해한 지점을 함께 본다. 빨리 끝났더라도 잘못 이해했다면 개선으로 보지 않는다. 소수 학생의 차이는 다음 수정의 단서로 사용하고 학습 효과가 입증됐다고 표현하지 않는다.

### 오해를 수정에 연결하기

| 단계·그림 요소 | 학생이 설명한 뜻 (익명 요약) | 원문과 다른 지점 | 수정 내용 | 다시 확인한 결과 |
|---|---|---|---|---|
| | | | | |

예: 대표 용기 하나만 처리하면 끝이라고 이해했다면 `repeat`를 보강한다. 물질과 용기의 대응이 바뀌었다면 이름표와 `mapping`을 가깝게 배치한다. 빗금을 실제 액체 상태로 이해했다면 생략 표시의 설명을 고친다.

결과를 공유할 때는 **자동 검사 통과 / 제작자 화면 검토 완료 / 학생 비교 검토 실시**를 구별해서 적고, 실제로 수행한 범위만 말한다.
